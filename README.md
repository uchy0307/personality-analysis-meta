# 200の問い 人格分析 (メタアプリ #000)

シリーズ「200の問い」全198本(app003〜app200)の履歴を横断分析する**最上位メタアプリ**。

## 特徴

- **localStorage/IndexedDB自動スキャン**: 同じドメイン上で他のappを実行していれば、自動でデータ収集
- **手動エントリ対応**: 過去の分析結果を手動で貼り付けて追加可能
- **メタ分析プロンプト生成**: 価値観の軸、思考傾向、感情パターン、行動傾向、強み、人生フェーズ、おすすめ次アプリを横断的に分析
- **SVGレーダーチャート**: 価値観5軸を可視化
- **シェア画像Canvas生成**: SNSで使えるPNG画像を出力
- **API呼び出しゼロ**: δ方式により永久無料・永久動作
- **PWA対応**: ホーム画面に追加可能、オフライン対応

## 使い方

1. このアプリを開く
2. 自動検出されたappデータを確認 (足りない場合は手動入力)
3. 「横断分析を始める」をクリック
4. 生成されたプロンプトをコピー → ChatGPT/Claude/Geminiに貼り付け
5. AIの応答をアプリに貼り戻す
6. 人格プロファイルが7つのカード+レーダーチャートで表示
7. シェア画像を生成してダウンロード

## 開発

```bash
npm install
npm run dev
```

## デプロイ

Vercelに接続するだけで自動デプロイ。
